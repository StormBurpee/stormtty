# README artwork

- `wordmark-light.svg` and `wordmark-dark.svg` are matching, outlined StormTTY
  wordmarks for GitHub's light and dark themes. The mark echoes a shell prompt;
  it is not a platform or upstream project logo.
- `smoke-concept.svg` is the editable source for `smoke-concept.png`. It adapts
  the Smoke design study into a shorter README composition. Terminal excerpts
  are illustrative content; the shell path has been generalized for publication.
  **Neither file is a screenshot of the native application.**
- The PNG uses Cascadia Mono for terminal text and DejaVu Sans for presentation
  labels. No font binary is included in these assets. The SVG intentionally
  declares fallbacks; rendering without Cascadia Mono will change text metrics.

Keep the concept label visible when reusing this image. Replace it with a real
native screenshot only after recording the platform, build and rendering path.
The concept does not establish compatibility, accessibility or performance.
